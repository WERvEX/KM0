KM0 的第一个版本：一句话描述要做的事，KM0 和你把需求与实现方案谈清楚，输出 PRD 和技术方案，再把实现拆成任务、为每个任务选模型档位和 Agent，生成可以直接交接的任务包。

## 包含的功能

- **分诊**：判断任务类型和复杂度，选择快速、轻量或完整通道，可以手动改。
- **讨论**：定位与规模、产品需求、技术选型、实现方案四个阶段提问，每轮最多 3 题；回答写进决策账本，回改决策只复核受影响的部分。
- **查证**：技术选型阶段用博查搜索 API 或 MCP 搜索服务查证最多 3 次，问题卡上列出来源。
- **关联本地仓库**：只读扫描依赖清单、语言和 CI 配置，识别出的技术栈直接写进技术选型。
- **文档**：生成 PRD 和技术方案，支持按小节编辑、AI 修订、版本恢复和过期标记。
- **任务路由**：按 T1/T2/T3 档位给任务选 Agent 和模型，估算成本并和“全部用 T3”对比。
- **交接**：为 Claude Code、Codex、Cursor、Pi、DSH、ZCode 和通用格式生成 zip 交接包。
- **配置导入导出**：模型、Agent、搜索服务等设置可以导出成 JSON 带到另一台电脑。
- 支持 OpenAI 兼容接口（OpenAI、DeepSeek、Qwen、GLM、MiMo 等）和 Anthropic 接口；API Key 由系统凭据存储加密，数据全部保存在本地。

## 下载

| 平台 | 文件 |
| --- | --- |
| Windows (x64) | `KM0-0.1.0-setup-x64.exe` |
| macOS (Apple 芯片) | `KM0-0.1.0-arm64.dmg` |
| macOS (Intel) | `KM0-0.1.0-x64.dmg` |
| Linux (x64) | `KM0-0.1.0-x86_64.AppImage` |

不想安装可以试网页调试版：<https://wervex.github.io/KM0/>，加 `?simulated=1` 用模拟模型，不需要 API Key。

## 注意

安装包暂未签名：
- Windows 会弹出 SmartScreen 提示，点“更多信息 → 仍要运行”。
- macOS 会提示“无法验证开发者”，在“系统设置 → 隐私与安全性”里点“仍要打开”，或右键应用选“打开”。
- Linux 的 AppImage 需要先 `chmod +x` 再运行。
