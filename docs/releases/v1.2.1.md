KM0 1.2.1：修复应用内更新说明与设置页宽度对齐问题，更新至 2026-11-21 最新模型能力榜单并新增 Antigravity CLI 识别，同时完成对任务路由、直接执行引擎、MCP 并发与跨平台稳定性的全面审计加固。

## 修复与改进

- **应用内更新与设置界面体验**：
  - 修复“设置 → 关于”中更新说明直接展示 GitHub Releases 原始 HTML 标签的问题，改为在本地安全转换为 Markdown 渲染（支持标题、列表、表格、行内代码、引用与链接）。
  - 统一设置页各标签页主内容区与展开表单（提供商、模型、搜索服务、执行设置）的宽度和对齐方式，修复表单展开后宽度与原卡片不匹配的问题。
  - 修复设置配置导出/导入漏掉模型上下文窗口覆盖、路由规则与执行选项的问题，升级为事务化导入并修复导入结果文案与自定义 Agent 匹配。
  - 修复模型注册表手动导入缺少 `dataDate` 校验、界面语言切换后“不支持自动更新”提示未更新、自定义 Agent 更新后残留不兼容模型绑定，以及执行中项目可被误删、验收结束后界面未自动刷新等细节问题。
- **最新模型能力榜单更新（数据截至 2026-11-21）**：
  - 同步公开榜单快照并重新拟合全部模型能力（覆盖 373 个模型、511 条观测记录，留出校验覆盖率 93%）。
  - 接入 Artificial Analysis 新版 `engineering_index` 编码指标以替代已置空的旧字段，新增 `Antigravity CLI` 与最新模型（Claude Fable 5.2、GPT-6.2 Astra、Gemini 4 系列、Qwen4 Max 等）的映射与拟合，显著收窄新模型的估计不确定度。
- **任务路由、直接执行与跨平台稳定性加固**：
  - 修复任务路由策略中的 `riskFloor` 分支错误，排除多分支合并冲突协调记录对任务失败历史与路由学习的干扰，并正确解析 `km0-<providerId>/<modelId>` 模型组合格式。
  - 加固直接执行引擎（DirectRun）：安全复用历史成功任务（跳过失败任务及已选重跑任务的传递下游依赖，防止污染最终集成分支）、补全异常与取消路径的 worktree 清理、强化预算耗尽中止、禁止 Claude Code 误提交 `km0/` 临时文件、完善集成分支冲突检查。
  - 修复 Windows 平台停止执行时未能终止完整子进程树与裸 CLI 命令解析失败的问题，补全 `which` 路径检查、输出读取边界处理，以及关闭应用前等待执行彻底收尾再关闭数据库。
  - 加固 MCP Server 并发领任务原子抢占（防止多会话重复领取同一任务）与工作区路径安全检查（防御大小写 `.git`、前缀绕过与悬空符号链接），并支持 SQLite 嵌套事务 `SAVEPOINT`、主进程单实例激活与 Web 调试模式串行持久化。

## 注意

- 安装包有没有签名取决于发布时是否配置了签名证书，本页末尾会写明。未签名时：
  - Windows 会弹出 SmartScreen 提示，点“更多信息 → 仍要运行”。
  - macOS 会提示“无法验证开发者”，在“系统设置 → 隐私与安全性”里点“仍要打开”，或右键应用选“打开”；未签名的 macOS 版本不能在应用内更新。
- Linux 的 AppImage 需要先 `chmod +x` 再运行；只有 AppImage 能在应用内更新。
- 订阅额度目前只统计 KM0 自己的调用，编码 Agent 的运行还没有计入。
